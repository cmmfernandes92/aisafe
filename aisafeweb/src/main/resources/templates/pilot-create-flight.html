Pilot Operations

Create Flight

Register a flight for a route and create its initial DRAFT flight plan. The flight's pilot is you, the signed-in user; you must belong to the route's company and be certified for the aircraft's model.

New Flight

POST /modules/pilot-operations/create-flight

A route can have at most one flight per day. The aircraft must belong to the route's company and not be decommissioned. The new flight starts with an empty DRAFT plan — use Import Flight Plan Import Flight Plan to load a validated DSL file into it.
